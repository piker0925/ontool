# 관리자 페이지 사이드바+라우트 구조 전환, TanStack Table 도입

**Status: superseded — 2026-07-25, 같은 날 재검토로 폐기.** 원래 사용자 요청은 "건의사항·댓글관리도 통계·유저관리처럼 각자 탭 하나씩 나눠달라"는 작은 요청이었는데, 그릴 인터뷰 진행자가 160 이슈 스텁에 이미 적혀있던 "현업 표준"이라는 표현을 shadcn `dashboard-01` 사이드바 패턴으로 확대 해석해 질문을 그 방향으로 이끌었다. 사용자가 매 질문에 답은 했지만 최종 결과물을 보고 "내 의도와 다르다"고 지적, 원래 의도(기존 상단 탭 방식 그대로 개수만 늘림)로 축소하기로 했다. 이 ADR이 기록한 사이드바+라우트+TanStack Table 결정은 **구현되지 않고 폐기됨** — 아래 원문은 무엇을 검토했었는지 기록으로만 남긴다. 실제 결정은 탭 개수만 늘리는 것으로, ADR을 남길 만한 "되돌리기 어려운 트레이드오프"가 아니라 별도 ADR 없이 이슈로 바로 진행한다.

---

관리자 페이지(`AdminPage.vue`, 1008줄)가 상단 탭 3개(통계/유저/운영) 안에 성격이 다른 섹션들을 계속 밀어넣는 방식으로 커져왔고, 특히 "운영" 탭 하나에 Job 큐 모니터링·건의사항·댓글 관리·댓글신고(유저별 누적/개별 목록)·관리자 액션 감사로그까지 6개 섹션이 눌러담겨 있었다. 2026-07-25 사용자가 "현업 표준" 구조로 리팩토링을 요청했고, 그릴 인터뷰 끝에 shadcn/ui `dashboard-01` 블록 패턴(접이식 좌측 사이드바 + 섹션별 라우트)을 참고해 5개 네비게이션 항목(대시보드 / 유저 관리 / 작업 큐 / 커뮤니티 관리 / 감사 로그)으로 재편하기로 결정했다. 기존 `?tab=` 쿼리파라미터 전환 방식은 폐기한다. 118(관리자 대시보드 시각화, 병합 완료)이 만든 차트 7종은 그대로 재사용한다.

같은 라운드에서 유저 목록·Job 목록·댓글신고 목록 표 3종을 정렬·필터·컬럼토글이 가능한 데이터테이블로 함께 교체하기로 하면서 `@tanstack/vue-table`을 신규 의존성으로 도입한다(이 프로젝트에 기존엔 테이블 라이브러리가 없었다).

## Considered Options

- 표 3종은 그대로 두고 네비게이션 구조만 바꾸는 안 — 스코프를 줄일 수 있었으나, 사용자가 "이번에 함께 고도화"를 확정해 반려.
- 데이터테이블을 의존성 추가 없이 직접 구현 — 데이터량이 수백 행 수준이라 가능했지만, 현업 표준 라이브러리 사용 경험 자체도 포트폴리오 가치가 있다고 판단해 TanStack Table을 채택.

## Consequences

- `AdminPage.vue` 단일 파일이 사이드바 셸 컴포넌트 + 섹션별 페이지 컴포넌트로 분리된다(신규 `/admin/*` 라우트 구조, 기존 `?tab=` 링크는 마이그레이션 대상에서 별도 리다이렉트 없이 폐기).
- 관리자 화면에 처음으로 외부 테이블 라이브러리 의존성이 생긴다 — 이후 관리자 표가 추가될 때는 TanStack Table을 기본으로 삼는다.
