# 2026년 요율/세액표 출처 기록

`/life` 생활 계산기(급여·금융·날짜)는 "공식 자료 기반, 근사식 금지"가 확정 방침(`.scratch/archive/v2-feature-list.md` §3)이라, 코드에 들어가는 모든 수치의 출처를 여기 기록한다. **매년 갱신이 필요한 값들**이라 다음 연도 작업 시 이 문서부터 다시 확인할 것.

값 자체는 `front/src/utils/salaryRates2026.ts`, `front/src/utils/withholdingTaxTable2026.ts`에 있다 — 이 문서는 "그 값을 어디서·언제·어떻게 확인했는지"만 다룬다.

## 신뢰도 표시 기준

- 🟢 **확정**: 정부 기관 1차 출처(보도자료·고시 원문·법령)를 직접 확인함
- 🟡 **약함**: 2차 출처(집계 사이트·블로그)로만 확인, 1차 고시 원문을 못 찾음 — 여러 독립 출처가 일치하면 실사용은 가능하나 원문 확인이 남아있음

### 자동 수집 실패 기록 (참고)

이 표는 처음엔 자동으로 못 가져왔다 — 국세청/홈택스가 배포하는 간이세액표 PDF는 HWP 변환 특성상 텍스트 레이어가 깨져 있어(바이너리로만 읽힘) 자동 파싱이 안 됐고, law.go.kr 별표 페이지는 JS 렌더링이라 일반 fetch로는 빈 페이지만 나왔다. 최종적으로 사용자가 홈택스에서 엑셀 파일을 직접 받아 `docs/data/`에 넣어줘서 해결— 엑셀 내부는 XML 텍스트라 파싱이 가능했다.

## LTV·DTI·DSR

값은 `front/src/utils/ltvDtiDsrCalc.ts`에 있다 — **정의(계산식)만 코드에 있고, 규제지역별 한도는 하드코딩하지 않았다.**

| 내용 | 신뢰도 | 출처 |
|---|---|---|
| LTV=대출금/주택가격, DTI=(주담대 연원리금+기타부채 연이자상환액)/연소득, DSR=모든 대출 연원리금상환액/연소득 | 🟢 | [국토연구원 용어사전 "총부채상환비율(DTI)"](https://www.krihs.re.kr/krihsLibraryDictionary/bbsView.es?pageIndex=3&num=87875) |
| 규제지역별 한도가 정책에 따라 자주 바뀐다는 근거: 2025-06-28(6.27대책) 규제지역 LTV 50%/비규제지역 70%로 강화 | 🟢 | [정책브리핑](https://www.korea.kr/news/policyNewsView.do?newsId=148945077) |
| 이후 2025-09-07 규제지역 LTV가 50%→40%로 추가 강화 | 🟡 | [경기일보](https://www.kyeonggi.com/article/20250907580152) — 2차 소스만 확인 |

**결론(설계 결정)**: 반년 새 두 차례 바뀔 만큼 유동적이라 하드코딩하지 않기로 함 — 계산기는 사용자가 입력한 금액으로 비율만 계산하고("간단 추정" 스코프), 화면에 "실제 한도는 대출 시점 금융기관·정부 공고 확인 필요" 안내만 표시한다.

## 청약저축 가점제 (주택공급에 관한 규칙 별표1)

값은 `front/src/utils/subscriptionScoreCalc.ts`에 있다.

| 항목 | 점수표 | 신뢰도 |
|---|---|---|
| 무주택기간 | 1년미만 2점, 이후 1년마다 2점씩 가산, 15년이상 32점(만점) | 🟡 |
| 부양가족수 | 0명 5점, 1명당 5점씩 가산, 6명이상 35점(만점) | 🟡 |
| 청약통장 가입기간 | 6개월미만 1점, 6개월~1년 2점, 이후 1년마다 1점씩 가산, 15년이상 17점(만점) | 🟡 |

[국가법령정보센터 별표1 링크](http://www.law.go.kr/lsBylInfoPLinkR.do?bylCls=BE&lsNm=%EC%A3%BC%ED%83%9D%EA%B3%B5%EA%B8%89%EC%97%90+%EA%B4%80%ED%95%9C+%EA%B7%9C%EC%B9%99&bylNo=0001&bylBrNo=00)는 JS 렌더링이라 원문 표 자체는 fetch로 못 읽었다(간이세액표 때와 동일 패턴). 위 숫자는 삼쩜삼 고객센터, zippoom.com 등 독립된 다수 2차 출처가 일치해 확인했다. 만점 합계 84점(32+35+17)이 "청약 가점제 만점은 84점"이라는 통설과 일치하는 것도 구조 검증에 참고. 2025-04-29 국토교통부령 제1486호 개정이 있었으나 검색 요약 기준 미성년자 가입기간 인정범위·동점자 처리 등 부수 조항 변경으로 보이고, 위 3개 항목 점수 구간표 자체가 바뀌었다는 근거는 못 찾음. **원문 별표1 PDF/HWP를 아직 직접 대조하지 못한 상태이니, 실사용 전 사용자가 law.go.kr에서 직접 받아 대조할 것을 권장**(간이세액표 케이스와 동일 해법).
